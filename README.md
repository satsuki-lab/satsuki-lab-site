# SATSUKI LAB — Website v0.1

個人研究所「SATSUKI LAB」の静的サイト試作品です。ビルドツール、外部ライブラリ、外部フォントは不要です。

## 内容

- `index.html` — ホーム / 主要プロジェクト / 作業ログ / 配布予定 / サツキの部屋への入口
- `projects.html` — プロジェクト一覧（カテゴリ切替可能）
- `satsuki-room.html` — 平成〜2000年代の個人ホームページ＋ブログ風の「サツキの部屋」
- `styles.css`, `script.js` — ラボ本体のデザインとナビゲーション、プロジェクト絞り込み
- `room.css`, `room.js` — サツキの部屋（カレンダー、壁紙切替、端末内訪問回数）
- `favicon.svg` — 仮のサイトアイコン

## 開き方

1. ZIPを解凍。
2. `index.html` をブラウザで開く。ネット接続は不要です。
3. `projects.html` のカテゴリボタンや「サツキの部屋」の壁紙ボタンを押して動作を確認してください。

※ ローカルファイルでの `localStorage` の扱いはブラウザ依存です。壁紙・訪問回数の保存は動かない場合がありますが、表示と基本操作には影響しません。

## 内容の編集

- プロジェクトの文章や状況：`index.html` と `projects.html` の該当部分
- LAB LOG：`index.html` の `id="lab-log"` 内
- 日記のサンプル：`satsuki-room.html` の `id="diary"` 内
- デザインカラー：`styles.css` の先頭 `:root` と `room.css` の先頭
- サツキの部屋の壁紙：`room.css` の `body[data-theme=...]`

## 公開案

GitHub Pages / Cloudflare Pages 等の静的サイト公開サービスに、このフォルダのファイルをそのまま配置する方式を想定しています。独自ドメインやフォーム、CMSは後から追加できます。

**公開前に確認すること**

- 文面・プロフィール・公開してよい開発情報の見直し
- 配布ソフトの権利・ライセンスおよび導入手順
- 写真・スクリーンショットは所有・使用許可のあるもののみ追加
- お問い合わせ、掲示板、アクセス解析などは必要になった段階でプライバシー方針やスパム対策を含め検討
- 日記の自動更新は**未実装**。現在の本文は明示的に創作サンプル
- `LAB ONLINE` は装飾表現でありサーバーのオンライン状態を検知していません
